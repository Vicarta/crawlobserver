# Phase 25.4 Plan 01

## Objective

Close the API/SPA routing ambiguity with the smallest compatible change, prove
the integration contract, and deploy only the app through existing safety gates.

## Tasks

1. Add the `/api` namespace guard to the existing SPA fallback and focused
   server tests for exact Current Snapshot JSON, both unknown `/api` path
   forms, public health JSON, and preservation of frontend fallback.
2. Correct API authentication response media types and extend middleware tests
   for missing and invalid credentials.
3. Document the behavior in `ProductFeatures.md`; run focused and repository
   gates, obtain independent review, and fix only blocking findings.
4. Commit and push the owned implementation. On `/opt/crawlobserver/app`, run
   `sudo -n env CHECK_ONLY=1 deploy/restart-app-safe.sh` with no `FORCE`, preserve
   the current app image as rollback evidence, build only the Compose `app`
   service, and repeat the same CHECK_ONLY gate immediately before restart.
   Run `deploy/restart-app-safe.sh` with no `FORCE`; do not run migrations or
   recreate ClickHouse, and confirm only the app container changed.
5. Execute the read-only production acceptance matrix, record exact evidence in
   `25.4-VERIFICATION.md`, close ROADMAP/STATE, then commit and push that GSD
   closeout separately so verification is present on the remote branch.
