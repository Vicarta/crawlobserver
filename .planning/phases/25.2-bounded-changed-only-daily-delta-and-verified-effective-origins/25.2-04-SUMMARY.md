# Plan 25.2-04 Summary

## Delivered

- Added optional `CrawlRequest.DiscoveryBudget` transport and persisted it in
  `CrawlerConfig`. A non-nil value is authoritative, including exact zero;
  nil leaves ordinary/full crawls unbounded by this additional counter.
- Daily Delta always provides the project discovery setting while keeping the
  existing `planned candidates + discovery budget` `MaxPages` total guard.
- Added one engine admission helper shared by static HTML and rendered DOM
  links (including `follow_js_links`). It applies scope, exclude, depth, and
  cancellation checks, then serializes the budget decision with `frontier.Add`.
  Only a successful unique add increments the discovery count.
- Seeds, sitemap/candidate insertion, and retries bypass the discovery
  counter. Duplicate, out-of-scope, excluded, depth-rejected, capacity-
  rejected, cancelled, and 304 paths do not consume it.
- Documented the independent exact Daily Delta discovery semantics in
  `ProductFeatures.md`.
