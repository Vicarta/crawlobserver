# Plan 25.2-01 Summary

## Delivered

- Added a strict reusable sitemap `lastmod` parser/comparator. It preserves raw
  values, accepts date or RFC3339 date-time values, compares mixed precision by
  UTC calendar date, and treats missing/invalid/equal/backward values as
  unchanged.
- Added the pure dual-term selector. Published sitemap evidence controls event
  eligibility; the newest raw observation only labels newly observed versus
  pending-unpublished retry provenance. Events are selected before deterministic
  rotating canaries and all deferred events keep explicit source provenance.
- Added persisted selection settings: evidence-backed sitemap events are
  eligible by default and prioritized before up to 50 canaries, subject to the
  existing changed/new/global safety ceilings. Existing limits stay unchanged,
  and negative values sanitize to zero.
- Added JSON-compatible `DeltaPlan` sitemap-selection lineage/results. A nil
  selection explicitly represents legacy sessions that predate the contract.
- Updated the Daily Delta product catalog entry with changed-only safety-term,
  bounds, audit provenance, and legacy behavior.
