## Core Invariants

1. An event is pending while fresh is ahead of P, even when R already contains
   the same event.
2. R can change event provenance but cannot make an event disappear.
3. `selected events + deferred events == all events ahead of P` after URL policy.
4. Canaries contain no event URL, contain no duplicate, and are stable for the
   same project/P/epoch tuple.
5. `selection_complete=false` or stale snapshot binding prevents sitemap safety
   term publication.
6. ETag/Last-Modified are copied exactly from the selected Current Snapshot page
   and only onto GET.
7. A 304 creates response evidence in the raw Delta but changes zero existing
   Current Snapshot page/link evidence rows.
8. A non-304 response follows the existing parser/render/overlay path.
9. Discovered admission never exceeds N under `go test -race`; N=0 admits none.
10. Seed candidates do not consume the discovered budget.
11. `effective_origin` is empty unless durable launched response evidence proves
    one non-conflicting origin.
12. Session API/UI still exposes the exact raw SeedURLs.

## Local Gate Sequence

1. `gofmt` changed Go files and run `git diff --check`.
2. Run focused selector/settings tests.
3. Run focused fetcher/crawler tests with `-race` for discovery concurrency.
4. Run required ClickHouse integration fixtures with fail-on-unavailable mode.
5. Run full Go suite.
6. Run frontend Vitest, lint, and production build.
7. Inspect diff for accidental Phase 26 implementation, seed rewrites, or
   unrelated files; commit and push the owned phase files.
8. On production, run the check-only active-crawl gate, build only `app`, run
   the gate again, and restart only `app` through the safe script. Never force.
9. Verify `/api/health`, Compose service state, ClickHouse `SELECT 1`, recent
   app logs, and read-only session API/UI origin rendering. Do not start a crawl.
