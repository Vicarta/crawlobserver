# Plan 25.2-03 Summary

## Delivered

- Added the optional conditional GET transport contract. Existing fetch callers
  remain unconditional, while enabled Delta requests send non-empty retained
  `ETag` and `Last-Modified` values exactly as `If-None-Match` and
  `If-Modified-Since` headers.
- Persisted the conditional-request setting and exact materialized baseline
  session in immutable DeltaPlan metadata. Preview/run/scheduler all build the
  same plan; manager startup loads case-insensitive retained baseline headers
  only for enabled Deltas.
- Made `304 Not Modified` a raw, durable Delta page record that returns before
  parsing, extractors, resource checks, JS rendering, and link discovery.
  Missing validators and non-304 responses retain normal behavior; no HEAD
  request is issued.

  existing page evidence and source links remain intact while the raw Delta row
  stays available for audit and coverage.

  Snapshot binding branch and before all materialized mutations. A retry no
  longer compares against the revision it already advanced.
- Updated `ProductFeatures.md` with actual validator behavior and 304 snapshot
  preservation.
