# Phase 25.2 Verification

## Result

Local implementation, regression gates, safe production rollout, and read-only
acceptance passed.

## Verified Contract

- Fresh sitemap planning compares the newest complete raw observation with the
  exact published Current Snapshot safety term.
- Only added URLs and strictly forward valid W3C `lastmod` values are changed
  events. Raw unpublished observations retain retry provenance but cannot
  consume a pending event.
- Evidence-backed events are prioritized before up to 50 deterministic rotating
  canaries. Existing changed/new/global settings remain safety ceilings rather
  than daily targets, so a quiet DI run is expected near its true changed set
  plus canaries while a genuinely broad change may legitimately run large.
- Conditional GET sends retained ETag/Last-Modified validators; `304` skips
  parsing, rendering, extraction, resources, and discovery while preserving the
  materialized page and link evidence.
- Static and rendered discovery share one exact concurrency-safe zero/N budget;
  planned candidates and retries do not consume it.
- Current Snapshot publication revalidates selector revision and exact lineage;
  deferred, stale, failed, incomplete, or untrusted work cannot advance the
  published sitemap safety term.
- Session list/detail reports an effective origin only from complete durable
  launched/final-response evidence. Raw seeds remain unchanged audit data.
