## Verified Contract

- A normalized unique email is attached to each migrated user without
  replacing existing identity, authorization, API-key, or active-session data.
- Invitations are random, hash-only, single-use, replaced on resend, and valid
  for seven days.
- Login requests are non-enumerating. The newest six-digit challenge is valid
  for 15 minutes, is single-use, and is invalidated after five failed attempts.
- Invitation acceptance and successful code verification create the existing
  cookie session with a 14-day expiry. HTTPS makes it Secure; logout revokes
  the stored session.
- The interactive password endpoint and UI are removed. Project-scoped and
  general API credentials retain their prior non-interactive behavior.
- Resend credentials remain server-side; provider calls have a bounded timeout,
  idempotency key, and redacted failures. Tests send no live email.
