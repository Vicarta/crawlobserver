# Product

## Register

product

## Users

SEO specialists, site owners, and agents using CrawlObserver to inspect crawl data, technical SEO issues, internal links, PageRank, and project quality.

## Product Purpose

CrawlObserver is an operational SEO crawl diagnostics tool. It helps users monitor current site state, trace crawl and source anomalies, evaluate data quality, and model internal linking changes before implementation.

## Brand Personality

Precise, calm, operational.

## Anti-references

Marketing landing-page composition, decorative dashboards, hidden diagnostics, modal-heavy workflows, and AI-looking visual decoration.

## Design Principles

- Make provenance visible whenever a URL appears problematic.
- Keep project workflows dense, scannable, and reversible.
- Separate current-site data from partial or delta data.
- Prefer explicit source and status evidence over ambiguous badges.
- Keep advanced SEO modeling accessible without hiding it behind technical session IDs.

## Accessibility & Inclusion

Product UI should target WCAG AA contrast, keyboard-operable controls, clear focus states, and no motion required to understand state.
