# Agent Rules

- Створюючи SSH ключ, завжди використовуй passphrase.
- Для команд через `ssh` не збирай складні one-liner-и з багаторівневим quoting.
- Якщо віддалена команда містить вкладені лапки, SQL, JSON, awk/sed або shell-підстановки, використовуй один із безпечних варіантів:
  - `ssh host 'bash -s' <<'EOF' ... EOF`
  - тимчасовий скрипт на сервері;
  - окремі прості команди замість одного великого конвеєра.
- Не виводь секрети в лог. Для паролів/токенів читай значення на віддаленому боці і передавай їх у команду без `echo`, `set -x` або друку конфіга.
- `ProductFeatures.md` є канонічним каталогом функціональності продукту. Кожна зміна, яка додає, змінює або видаляє користувацьку, API, crawler, reporting, integration чи operational функціональність, повинна в тому самому наборі змін оновлювати `ProductFeatures.md`.
